# M2.1 双单元厂区总览更新

- **同屏功能完成**：同一renderer/场景/相机展示两座原始设备，共用带两处开口的地面、连接道路和少量复用绿化材质的种植带。两座池的Blend、GLB、几何、材质未修改；只按配置平移，无缩放、二次轴向转换或虚构连接管线。
- **交互快检通过**：33项单测、类型检查及生产构建通过。26项受影响浏览器快检验证点击选择、两池连续定位、各模式复位、局部水面、单份加载失败、USER来源告警定位、模式切换取消和缓存复用。最终文案修正后补验冷加载竞态、真实隐藏PAGE_HIDDEN、两份独立预览与1366紧凑布局，均通过。
- **本轮活动目标达标，未宣称长期正式性能验收通过**：仅一次候选连续确认，不重测原完整效果模式；厂区入口保持“试运行”，默认仍是原单元查看。
- **视觉待用户确认**，尺寸与场地均为演示，不是施工或工艺工程设计。

## 使用

运行 `pnpm preview`，访问 http://127.0.0.1:4173/ ，在三维工具栏“视图模式”选择“厂区总览 · 试运行”。保留“单元查看”及 http://127.0.0.1:4173/viewer.html?model=clarifier 独立预览。

口令仍只有确定性解析后的两个工具：两条“定位一号…”共用 `scene.focus_device`；“回到总览”共用 `scene.reset_view`。厂区复位恢复双单元视角，单元复位恢复原单池视角。水面按钮只控制选中设备；未选择时禁用。

二沉池详情、告警、趋势显示“暂无该设备数据”，不借用曝气池曲线或阈值。顶部KPI明确保持原曝气池/关联鼓风机数据，数据场景和历史执行记录不因模式切换清空。

## 实现及保护

GLB节点检查见 `asset-nodes.json`：两份资产均为独立设备根节点 + `SW_SITE_CONTEXT`，相机/灯光均0。厂区只挂设备根节点，不挂两份原局部场地。共用地面开口采用原外壁尺寸，地面顶Y=0；射线单测确认两池内部无地面、池间地面存在。位置/角度/间距集中 `config/plant-layout.json`：曝气池X=-22m，二沉池X=31m，比例均1，场地104×44m。

改动职责：`src/scene/runtime.ts` 增量装配/分设备状态/水面/DOM标签；`deviceRegistry.ts` 支持同一注册表的两设备；新增 `assetCache.ts` 与 `plantSite.ts`；`useSceneWorkspace` 协调普通模式切换与旧动作取消。界面与数据联动修改 `App.vue`、`useDashboardContext.ts`、`SceneViewport`、`AgentWorkspace`、`DeviceSummary`、`AlarmPanel`、`TrendPanel`、`KpiOverview`、实体说明及样式；QA接口和 `tests/plantOverview.test.ts` 支持补验。完整实际文件清单在 `integrity.json`。

运行时仅缓存两种正式GLB的在途Promise/解析结果，切换复用实例，迟到结果须通过generation校验。设备及原场地由缓存统一拥有；新共同场地只释放自己创建的资源，环境由runtime拥有；不会因退出一个单元释放另一个仍用的材质。缓存保留已访问单元资源直到runtime销毁，这是减少重复解析的内存取舍。没有合批、模型降质、DPR调整或重建renderer。

修改前源码归档 `.cache/m21-before.tgz`。原233份受保护证据、参考图及两组Blend/GLB摘要复核不变，未操作交互Blender。生产构建保留原>500kB chunk提醒；没有安装或升级依赖。

## 一次连续确认结果

沿用约定M3环境，Chrome156；页面1920×1080，原生DPR2，三维DPR1；固定CSS视口/实际drawing buffer 1218×427。交互优先；相机段双趋势和统一模拟刷新均开启，每10秒切换演示场景/时间范围。预热2次镜头后采样，整个确认不重载、无截图/Blender/轨迹分析并发。随后连续12组定位/取消/复位及面板操作，共24条终态，4条预期CANCELLED、其余SUCCEEDED。

| 活动阶段 | 采样秒 | 场景提交FPS | 原始间隔P95 | >50ms / >100ms |
|---|---:|---:|---:|---:|
| 持续移动 + 数据 + 双趋势 | 122.91 | 59.11 | 18.4ms | 16 / 1 |
| 定位/取消/复位/面板 | 19.29 | 57.13 | 18.5ms | 9 / 1 |

连续总时长144.05s，两段均全程可见。FPS按提交次数/采样时长计算，P95使用未截断rAF间隔，不是GPU耗时或显示器呈现FPS；空闲停绘未计成高FPS。面板操作段包含尺寸变化，不与固定镜头段混成单一成绩。原始数据 `confirmation.json` 保留全部长帧：仍有2次>100ms间隔，不能据此宣称长期稳定。

冷解析记录：曝气池405.9ms、二沉池877.2ms（含下载/解码/解析，不是纯网络耗时）。活动时125 draw calls、场景167,624三角面；10秒资源样本保持1 renderer、134几何、23纹理、5程序，数量不是显存字节。其他用户原有标签页未关闭，处于后台；此结论不扩展至DPR2三维、多浏览器、移动端或全厂负载。
