## 工具、快照与执行

完整输入 Schema、结果字段、错误码、权限和上限见 [tool-contracts.json](tool-contracts.json)，来源为实际工具定义与实现。

| 工具 | 权限 | 主要结果 | 单次上限 |
|---|---|---|---|
| scene.focus_device / scene.reset_view | 受控展示 | 实际相机、选中、渲染帧和到位确认 | 各6.5s |
| device.get_details | 只读 | 设备资料、单元/机械节点、模型加载状态、指标列表；运行状态NOT_OBSERVED | 2s |
| device.get_metrics | 只读 | 归属设备的原始读数；1/6/24h有效/缺测/过期样本、覆盖、最小/最大/均值 | 2s |
| chart.show_trend | 受控展示 | 相同任务快照的曲线与实际setOption提交证明 | 3s |
| alarm.list / alarm.inspect | 只读 | 原有告警、发生时间、触发值、演示规则、事件与当前质量 | 各2s |

所有输入拒绝额外字段（包括__proto__/constructor/toString等继承字段名）、错误类型、越界时窗、错误指标归属和设备控制请求。参数最多4096字节；历史最多1441样本。结果携带真实evidence_id、snapshot_id、as_of、source及quality。告警事件没有精确历史匹配时标记NOT_RECORDED，不推定质量。

任务启动复制并固定scenario/snapshot/as_of；相对时间基于演示时钟。后台快照前进后，任务统计和目标图表保持原快照且显示“截至”。普通范围切换退出固定曲线；重开证据趋势通过同一Dispatcher记为USER。每任务最多6次模型请求、20次工具、120s；查询/展示失败分开，保留PARTIAL、FAILED、CANCELLED及已完成证据。最近10项任务保留原始历史快照，其他执行记录不静默删除。

### 活动性能快检（不替代正式性能验收）

沿用本机Apple M3环境，Chrome 156，页面1920×1080；浏览器原生DPR=2，三维实际倍率=1；三维CSS与drawing buffer均1218×427。四单元、双趋势、5s模拟刷新开启；固定连续镜头路径，期间每10s执行一次九步巡检。无并行Blender制作、截图或高开销轨迹。

预热两个镜头动作后，采样 **61.83s**：场景提交平均 **57.21 FPS**，原始rAF间隔 **P95 17.6ms**，>50ms **26次**，>100ms **7次**。六项巡检均成功。renderer=1、图表=2、数据定时器=1，观察器/监听器及模型请求次数未增长。原始帧间隔在 [activity-quick-check.json](activity-quick-check.json)。

参数额外字段加固前的r4快检也完整保留在activity-r4.json：61.48s，58.77 FPS，P95 18.4ms，>50ms 9次、>100ms 4次。两份均保留，以最终构建结果作为交付快检，未混用较好成绩。

该活动窗口达到≥45 FPS/P95≤40ms的数值目标；长帧仍存在。提交速率不是显示器呈现帧率，rAF不是GPU耗时；未将空闲按需停绘算成高FPS。未进行本轮正式长时矩阵、DPR2三维、多浏览器或真实模型负载性能验收。

## 启动与范围限制

在项目目录分别启动：

```sh
pnpm agent:gateway
pnpm dev
```

开发地址：<http://127.0.0.1:5173/>。固定生产构建预览：`pnpm preview`，地址 <http://127.0.0.1:4173/>。两者都代理`/api/agent`到仅监听127.0.0.1:8787的网关；不是任意URL代理。

凭据仅由服务端读取`.env.gateway.local`中的`SMARTWATER_OPENAI_API_KEY`与`SMARTWATER_MODEL`，无密钥示例为项目根`.env.gateway.example`。不写入VITE变量、浏览器存储、客户端构建或日志；构建扫描未发现服务端端点代码和测试凭据。当前没有实际凭据，不能宣称真实模型联网成功。模型配置后需重新启动网关并点击“检查连接”；不承诺所有模型均支持该协议参数。

按[官方函数调用说明](https://developers.openai.com/api/docs/guides/function-calling)与[Chat Completions接口](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)实现function/tool_call_id循环；带点内部名称显式映射为下划线函数名，客户端始终复用同一工具校验和执行器。模型仅接收必要资料/统计及有限证据，不发送逐点历史。

任务A须在已载入鼓风机的单元查看或四单元试运行下执行；目标未载入/场景未就绪时定位失败，查询仍可完成并标为部分完成，不自动重载GLB。二沉池和提升泵没有指标；pH/水深没有既定历史曲线。网关与协议测试夹具不等于真实模型验证；真实供应商兼容性、真实模型回复质量及模型请求期间的端到端取消仍未验证。本地取消保证停止后续调度、丢弃迟到回复并取消本地可取消请求，不保证上游计算或计费停止。
