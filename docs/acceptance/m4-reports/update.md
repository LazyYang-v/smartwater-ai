# SmartWater v0.1 · M4 交付更新

已实现任务历史、IndexedDB 存档、固定报告及 Markdown / JSON 导出。待用户体验验收；不是完整污水厂或生产系统认证。

## 实际实现

- 复用原任务执行器与 Dispatcher：仅增加任务建立 / 终态及逐工具回执观察接口。保存与执行状态分开；短事务提交后才显示已保存。
- 新增当前任务 / 历史任务入口、按页列表、单任务详情、明确重执行。重执行新建 task_id、引用原 ID、获取新快照，保留原任务当时模式。
- 报告由程序从冻结工具结果、演示规则和设备目录快照组成。实际模型文字独立展示；无完整曲线时明确说明，查看历史不调用当前数据源补图。
- Web Locks 限制同站点一个活动 Agent 标签页。只在取得排他执行权后恢复未确认终态任务；显示“执行中断 / 结果未确认”，不重放请求或工具。
- 配额 / 写入失败保留内存结果，可导出和明确重试。无删除旧记录腾空间机制。固定模板文本展示，不执行模型 HTML 或加载其远程图片。
- 模型、材质、场地、两个查看方式、网关和七个工具保持原有实现；四单元入口仍为试运行，默认仍为单元查看。没有安装 / 升级依赖。

修改清单：[modified-files.json](modified-files.json)。修改前源码归档在项目 `.cache/m4-before.tgz`；原 Git 树均为未跟踪文件，未进行清理、重置或推送。
