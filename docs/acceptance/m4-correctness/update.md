# M4 正确性修订

基线：`e57b69e`。落实本次源码审查的第一步：任务完成判定、指标汇总、预览入口和项目指令同步。没有修改模型、材质、布局、网关协议或依赖；资产体积 / 缓存优化与 Java 业务阶段留待独立实施。

## 修复与证据

1. **完成判定缺少参数。** 原 `completionGaps()` 仅按精确模板文字核对工具 / 设备，合法的一小时查询与展示足以满足六小时任务。已先用真实执行器 + 离线协议输入复现（[失败日志](reproduction.log)），再在任务建立时冻结版本化的设备、指标、时窗和展示要求。查询和展示分别检查；核对实际历史起止时间、同任务 / 快照、设备 / 指标归属及展示回执，较早正确展示不能掩盖后续错误展示。未满足时继续反馈缺失结果，仍由模型自行选工具；预算耗尽保留 PARTIAL 与明确未完成要求。已覆盖两条原真实联调同义表述。无法识别完整要求的请求不宣告整项成功；不支持 / 含歧义的时窗在模型请求前明确失败。这是有限的需求约束解析，不宣称已覆盖任意自然语言。
2. **汇总只取第一条指标证据。** 原结果卡和报告各自 `.find()`，pH 后查 DO 会漏掉 DO。已共用 `evidenceSummary.ts`：按设备 / 指标合并同版本的全部成功查询与趋势查询结果，重复读数去重，1h / 6h 等历史统计各自保留及引用，跨版本证据不混入，同版本冲突保持无法判断。结果卡、历史详情、Markdown / JSON 均使用完整指标明细；旧冻结报告不自动重算。
3. **独立预览固定指向二沉池。** [旧网页结果](preview-before.json) 确认鼓风机页面仍指向 clarifier。现在根据统一单元目录和当前设备生成 URL；厂区未选设备时提示先选择。实际点击鼓风机入口后，独立查看器加载了鼓风机 GLB；泵入口和 Agent 选择后的链接也正确。
4. **项目指令过期。** `AGENTS.md` 已同步四单元、七个工具、真实模型网关、模拟数据、历史报告及当前正确性范围，保留资产 / 证据 / 密钥、实际展示、取消和存储保护。后续 Java 阶段仍需独立明确范围。
